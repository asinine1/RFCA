# Project Context

This folder is the pre-code workspace for the rolling
diffusion-autoregressive generation project.

The active direction is a hybrid language-model architecture: a diffusion
model maintains a provisional future canvas, while an autoregressive
solidifier reads that canvas and commits the next token. The working name is
Rolling Future-Conditioned Autoregression (RFCA), which is provisional until
the literature review establishes the clearest terminology.

Capture the research question, constraints, terminology, literature notes,
hypotheses, experiment criteria, and decisions here before implementation
begins.
