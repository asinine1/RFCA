# Agent Instructions

## Conversation workflow

- At the start of every conversation, read `SCRATCHPAD.md` before taking action. Use it to recover the latest project context, decisions, open questions, and next steps.
- At the end of every turn, update `SCRATCHPAD.md` with a concise record of what was done in that turn, including relevant files changed, decisions made, verification performed, and any remaining work or blockers.
- Keep `SCRATCHPAD.md` current and factual. Do not erase useful prior context; revise outdated items when needed.

## Working principles

- Be honest and gently critical. If something is weak, say so clearly and explain why; if it is good, say so accurately.
- Do not invent products, features, references, evidence, or completed work. Build requested functionality fully rather than leaving hollow pages or fake references.
- Preserve existing user work and unrelated changes. Make the smallest safe change that fulfills the request.
- Verify changes in proportion to their risk and report what was checked.

## Repository context

- The repository is an ISEF 2027 research/project workspace.
- Treat research claims, citations, and project data as especially important to verify and keep traceable.
